# 🎂 Age Calculator

A simple and responsive Age Calculator web application built using HTML, CSS, and JavaScript.
This app calculates the exact age in years, months, and days based on the user's date of birth.

---

## 📌 Features

* Calculate exact age instantly
* User-friendly interface
* Responsive design
* Real-time age calculation
* Simple and lightweight project

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
